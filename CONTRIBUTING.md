# Contributing to TriAngels Infrastructure

TriAngels Infrastructure — это распределённая mesh-сеть, построенная на основе Headscale + Tailscale.

Мы приветствуем партнёров, которые хотят участвовать в развитии сети.

---

# Ways to Contribute

Партнёры могут участвовать следующим образом:

• запуск Exit Nodes  
• развитие инфраструктуры  
• документация  
• DevOps автоматизация  
• тестирование сети  

---

# Exit Node Contribution

Если вы хотите развернуть Exit Node, выполните следующие шаги.

### Requirements

Минимальные требования VPS:

CPU: 1 vCPU  
RAM: 1 GB  
Disk: 20 GB  
OS: Ubuntu 22.04 LTS

# Security Model

TriAngels использует:

• Zero-Trust Architecture  
• WireGuard encryption  
• Headscale Control Plane  
• Tag-based ACL  

---

# Join the Network

Для подключения к инфраструктуре TriAngels:

1. Подготовьте VPS
2. Следуйте инструкции Exit Node Deployment
3. Получите авторизацию у администратора сети
